# Bundled fonts — licenses and sources

All bundled WOFF2 files in `source-assets/fonts/` are subsets (latin-only) of
permissively-licensed typefaces. Each is redistributable under the SIL Open
Font License (OFL) Version 1.1. Subsets were obtained from the Bunny Fonts
CDN, which mirrors the upstream OFL releases.

| Family | Upstream | License |
| --- | --- | --- |
| Geist, Geist Mono | https://github.com/vercel/geist-font | SIL OFL 1.1 |
| Inter | https://github.com/rsms/inter | SIL OFL 1.1 |
| IBM Plex Sans, IBM Plex Mono | https://github.com/IBM/plex | SIL OFL 1.1 |
| JetBrains Mono | https://github.com/JetBrains/JetBrainsMono | SIL OFL 1.1 |

The full text of SIL OFL 1.1 is available at:
https://scripts.sil.org/cms/scripts/page.php?item_id=OFL_web

The OFL permits:
- Use in any project, commercial or non-commercial
- Redistribution of the unmodified font files
- Bundling with other software

The OFL requires:
- Modified font files must be renamed
- License notice retained when redistributing
